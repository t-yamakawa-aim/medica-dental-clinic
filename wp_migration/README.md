# medica-dental-clinic → WordPress 移行パッケージ

## このパッケージの中身

```
wp_migration/
├── medica-clinic-import.xml   ← WordPress標準インポートファイル(お知らせ24件+ブログ10件)
├── images/
│   ├── blog_thumbnails/       ← ブログ記事のアイキャッチ画像(サムネイル)
│   ├── body_images/           ← ブログ・お知らせ本文中に埋め込まれていた画像
│   └── site_images/           ← サイト全体で使っている画像(ロゴ、施設写真、症状別写真など)
├── site_content_reference_site.ts     ← 当院紹介・診療案内・採用情報などの文章(固定ページ作成の参考資料)
├── site_content_reference_symptoms.ts ← 症状別ページの文章(参考資料)
└── README.md                  ← このファイル
```

## ⚠️ 移行できなかったもの

- ブログ記事「**子どものむし歯予防、いつから始める？**」のサムネイル画像・本文中画像が、
  元のURL自体が失効しており取得できませんでした。この記事だけは画像なしでインポートされます。
  → WordPress側で新しい画像を用意して差し替えてください。

## インポート手順(WordPress管理画面での作業)

### 手順1: 記事(お知らせ・ブログ)のインポート

1. WordPress管理画面にログイン
2. 「ツール」→「インポート」を開く
3. 「WordPress」の項目で「今すぐインストール」→「インポーターの実行」
4. `medica-clinic-import.xml` をアップロードして「ファイルをアップロードしてインポート」
5. 投稿者の割り当て画面が出るので、既存のユーザーを選択(または新規作成)
6. 「添付ファイルをダウンロードしてインポートする」のチェックは **外したままでOK**(画像は元URLが外部のため取得できません。手順2で手動アップロードします)
7. 「インポート」を実行

→ これで「お知らせ」24件、「ブログ」10件が下書き記事として取り込まれます(カテゴリー「お知らせ」「ブログ」で分類済み)。

### 手順2: 画像のアップロードと差し替え

インポートされた記事の本文には、`[[IMAGE:ファイル名]]` や `[[THUMBNAIL:ファイル名]]` という**プレースホルダー文字列**が入っています。これは「ここに元々この画像が入っていました」という目印です。

1. 「メディア」→「新規追加」で、`images/blog_thumbnails/` と `images/body_images/` の中の画像を**全部まとめてアップロード**
2. アップロード後、各画像のURL(メディアライブラリで画像をクリックすると表示される「ファイルURL」)をコピー
3. 該当する記事を編集画面で開き、`[[IMAGE:blog-thumb-1.jpg]]` のような文字列を探して、そのURLに置き換える
   - `[[THUMBNAIL:xxx.jpg]]` の行は、本文に残しても良いですが、できれば削除して、代わりに**WordPressの「アイキャッチ画像」機能**でその画像を設定するのがおすすめです(WordPressテーマ側でアイキャッチを一覧表示に使えるため)。
4. `[[IMAGE:xxx.jpg]]` は本文中の画像として、`<img>` タグの `src=` 部分をそのままメディアURLに置き換えてください。

※ 記事数が多いため、手作業が大変な場合は、慣れている方に依頼するか、Genspark側で再度サポートしますのでお声がけください。

### 手順3: サイト全体の画像アップロード

`images/site_images/` の中の画像(ロゴ、施設写真、症状別の写真など、計6MB)は、固定ページやテーマのカスタマイズで使う想定です。「メディア」→「新規追加」でまとめてアップロードしておくと、固定ページ作成時にすぐ使えます。

### 手順4: 固定ページの作成(当院について・症状別など)

`site_content_reference_site.ts` と `site_content_reference_symptoms.ts` に、現在のサイトで使われている以下の文章が入っています。
拡張子は `.ts` ですが、中身は開発時のプログラムコードで、日本語のテキスト部分(`'...'` や `"..."` で囲まれた文章)だけを見れば内容が読み取れます。**メモ帳やテキストエディタで開いて構いません。**

`site_content_reference_site.ts` の内容:
- クリニック基本情報(名称・電話番号・住所・診療時間)
- 診療理念・院長紹介・当院概要
- 施設・設備紹介
- 感染症対策
- スタッフ紹介
- 診療の流れ
- 採用情報

`site_content_reference_symptoms.ts` の内容:
- 症状別ページの文章(虫歯、歯周病、矯正、インプラント等 多数)

これらを参考に、WordPress側で固定ページ(「当院について」「診療案内」「症状別で探す」「採用情報」等)を新規作成し、コピー&編集して配置してください。

## 予約システムへの導線

予約フォームは今後も Cloudflare 側 (`https://medica-dental-clinic.pages.dev/reserve`) で運用します。
WordPressサイトの目立つ場所(ヘッダー、フッター、トップページ等)に、以下のようなボタン・リンクを設置してください:

```html
<a href="https://medica-dental-clinic.pages.dev/reserve" class="button">Web予約はこちら</a>
```
